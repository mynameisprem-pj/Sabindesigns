# 🎨 Sabin Designs — Graphic Designer Portfolio

A sleek, responsive, and performance-focused portfolio website built for **Sabin**, a graphic designer. Designed to highlight creative projects, branding concepts, and visual artistry with clean layouts and interactive elements.

🔗 **Live Website:** [sabindesigns.vercel.app](https://sabindesigns.vercel.app)  
📁 **GitHub Repository:** [mynameisprem-pj/sabindesigns](https://github.com/mynameisprem-pj/Sabindesigns)

---

## ✨ Features

* **Visual Project Showcase:** Highlighting graphic design work with responsive image galleries and clean presentation.
* **Modern & Clean UI:** Thoughtful typography, smooth hover effects, and intuitive navigation tailored for a creative portfolio.
* **Fully Responsive:** Optimized across mobile, tablet, and desktop screens for a seamless viewing experience.
* **Lightweight & Fast:** Built with pure web standards (HTML, CSS, JavaScript) for instant page loads and zero bundle overhead.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic markup and structure
* **CSS3:** Custom styles, Flexbox/Grid layouts, and responsive media queries
* **JavaScript (ES6+):** Client-side interactivity and dynamic UI behavior
* **Deployment:** [Vercel](https://vercel.com/)
